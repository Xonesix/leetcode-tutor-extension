# LeetCode Tutor Extension
Short description of what the extension does and why it is useful.

## Quick Start
1. Clone the repo.
2. Run `git pull` to make sure you are up to date.
3. Open Chrome and click the puzzle piece icon.

## Install (Load Unpacked)
1. Click the puzzle piece icon, then **Manage extensions**.
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** and select this folder.

## Usage
Click the puzzle piece icon and launch the extension.
