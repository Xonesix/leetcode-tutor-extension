## How to use
After cloning repo make sure to run `git pull` to sync changes

Click the puzzle piece on chrome
![Extension Manage Popup](./readmeassets/Screenshot%202026-02-03%20at%202.17.40 PM.png)
Click manage extensions, you should see this screen
![Loading Extensions](./readmeassets/Screenshot%202026-02-03%20at%202.17.52 PM.png)
Click load unpacked and select the folder
![Accessing Extension](./readmeassets/Screenshot%202026-02-03%20at%202.18.11 PM.png)

Running the extension, just click on the extension puzzle piece and it should work
![Running Extension](./readmeassets/Screenshot%202026-02-03%20at%202.20.08 PM.png)
